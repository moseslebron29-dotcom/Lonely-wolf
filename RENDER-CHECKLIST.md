# Render checklist

[ ] GitHub repository created
[ ] ZIP contents uploaded at repository root
[ ] `package.json` visible at root
[ ] Render Web Service connected to GitHub
[ ] Build command: `npm install`
[ ] Start command: `npm start`
[ ] `OWNER_NUMBER` set
[ ] Persistent disk configured for `/var/data`
[ ] Deploy completed
[ ] `/health` returns JSON
[ ] Pairing page opens
[ ] WhatsApp pairing completed
[ ] `.ping` tested
[ ] `.menu` tested

If deployment fails, inspect Render Logs first. The most useful first error is normally near the bottom of the startup stack trace.
